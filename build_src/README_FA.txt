Live Signal Assistant — نسخه اولیه قابل ساخت برای اندروید

این برنامه:
- با اجازه خودت صفحه گوشی را به‌صورت زنده می‌بیند.
- روی صفحه یک حباب شناور نشان می‌دهد.
- فقط یکی از سه خروجی را می‌دهد:
  ↑ UP + زمان
  ↓ DOWN + زمان
  WAIT
- هیچ کلیک، سفارش یا معامله خودکاری انجام نمی‌دهد.

نکته مهم:
این نسخه «مدل آموزش‌دیده اختصاصی Pocket Option» نیست؛ تحلیل اولیه روی تصویر چارت و مومنتوم رنگ کندل‌ها انجام می‌شود.
پس قبل از استفاده با پول واقعی باید دقتش روی همان چارت و همان تنظیمات تست و کالیبره شود.

برای ساخت APK در GitHub:
1) محتویات این ZIP را از حالت فشرده خارج کن.
2) همه فایل‌ها و پوشه‌ها را داخل Repository آپلود کن.
3) وارد تب Actions شو.
4) Workflow با نام Build Android APK را اجرا کن.
5) بعد از سبز شدن Build، Artifact به نام LiveSignalAssistant-debug را دانلود کن.
6) ZIP آرتیفکت را باز کن و app-debug.apk را نصب کن.
7) داخل برنامه:
   - اجازه Display over other apps را بده.
   - Start screen capture را بزن.
   - در پنجره اندروید اجازه ضبط صفحه را تأیید کن.
   - بعد Pocket Option را باز کن.

این پروژه صرفاً دستیار تحلیلی است و معامله را خودکار اجرا نمی‌کند.
